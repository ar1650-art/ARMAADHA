ARMAADHA – BIRTHDAY POSTER UPDATE

പുതിയ സൗകര്യം:
1. Dashboard-ൽ ഇന്ന് ജന്മദിനമുള്ള വിദ്യാർത്ഥികളുടെ പേര് + പ്രൊഫൈൽ ഫോട്ടോ മാത്രം കാണിക്കും.
2. ഓരോ വിദ്യാർത്ഥിയുടെയും അടുത്ത് “Create Poster” ബട്ടൺ കാണും.
3. ബട്ടൺ അമർത്തുമ്പോൾ ARMAADHA നീല ഗ്രാഫിക് ഡിസൈനിൽ Birthday Poster തയ്യാറാകും.
4. വിദ്യാർത്ഥിയുടെ പ്രൊഫൈൽ ഫോട്ടോ, പേര്, AR ID എന്നിവ പോസ്റ്ററിൽ സ്വയം വരും.
5. “Download Poster” അമർത്തി PNG ആയി ഡൗൺലോഡ് ചെയ്യാം.

ഇൻസ്റ്റാൾ:
- ഈ ZIP extract ചെയ്യുക.
- GitHub repository-യിലെ index.html മാത്രം replace ചെയ്ത് commit ചെയ്യുക.
- Code.gs, config.js, മറ്റ് ഫയലുകൾ മാറ്റേണ്ടതില്ല.
- Browser-ൽ Ctrl + Shift + R അമർത്തുക.

കുറിപ്പ്:
