ARMAADHA – Dashboard Poster Display അപ്ഡേറ്റ്

മാറ്റങ്ങൾ:
1. Dashboard തുറക്കുമ്പോൾ Birthday / Event Poster ഭാഗം ഏറ്റവും മുകളിൽ, Dashboard heading-ന് തൊട്ടുതാഴെ കാണിക്കും.
2. ഇന്ന് ജന്മദിനമുള്ള വിദ്യാർത്ഥികൾ ഉണ്ടെങ്കിൽ അവരുടെ Birthday Poster കാണിക്കും.
3. വരാനിരിക്കുന്ന Events ഉണ്ടെങ്കിൽ അവയുടെ Event Poster / വിവരങ്ങൾ കാണിക്കും.
4. ജന്മദിനവും വരാനിരിക്കുന്ന Event-ഉം ഒന്നുമില്ലെങ്കിൽ Poster ഭാഗം പൂർണ്ണമായും മറയ്ക്കും. ശൂന്യമായ ബോക്സോ സന്ദേശമോ കാണിക്കില്ല.
5. Birthday poster-ൽ App background, Happy Birthday, ആശംസാ വാചകം, വിദ്യാർത്ഥിയുടെ യഥാർത്ഥ Profile Photo, പേര് എന്നിവ മാത്രം കാണിക്കും.
6. നിലവിലുള്ള Events, profile photo, payment, expense, login, category ഡാറ്റ മാറ്റുകയോ reset ചെയ്യുകയോ ചെയ്യുന്നില്ല.

ഇൻസ്റ്റാൾ:
1. ZIP Extract ചെയ്യുക.
2. GitHub repository-യിലെ index.html replace ചെയ്ത് Commit Changes ചെയ്യുക.
3. Code.gs, config.js എന്നിവ മാറ്റേണ്ടതില്ല.
4. Browser-ൽ Ctrl + Shift + R അമർത്തുക.

കുറിപ്പ്: JavaScript syntax പരിശോധിച്ചു. Live GitHub / Apps Script deployment പരീക്ഷിച്ചിട്ടില്ല.
