ARMAADHA – THREE APP THEMES

Included themes in Settings > Appearance:
1. Dark Theme – modern charcoal / slate interface.
2. Light Theme – clean light interface.
3. ARMAADHA Signature Theme – original burgundy and gold brand colors.

The selected theme is saved in the current browser/device and restored on next visit.

INSTALL
1. Extract this ZIP.
2. Replace only index.html in your GitHub Pages repository with this index.html.
3. Commit / push the change.
4. Refresh the app (Ctrl + Shift + R on desktop).

Do not replace Code.gs, config.js, manifest.webmanifest, or service-worker.js for this theme update.

Validation: inline JavaScript syntax checked and ZIP integrity checked. Live deployment was not tested.
