ARMAADHA — SEPARATE ADMIN & STUDENT SETTINGS

Included:
- Separate Settings page for Admin and Student roles.
- Admin sees administrator account information, admin-only settings information, and sign-out controls.
- Student sees their own account information, password-change form, theme preference, and sign-out controls.
- Students cannot see or open Admin Settings.
- Light/Dark theme preference is saved on the current device.
- Existing mobile hamburger-only side menu and desktop layout are retained.

INSTALL:
1. Extract this ZIP.
2. Replace only index.html in the existing GitHub Pages repository.
3. Keep Code.gs, config.js, manifest.webmanifest, service-worker.js and icons unchanged.
4. Commit/push the change.
5. Open the app and hard refresh (Ctrl+Shift+R).

IMPORTANT:
- No spreadsheet, student, payment, expense, category, login-account or Script Properties data is reset.
- The current backend supports password changes for student accounts only. Admin password changes are not enabled, so the Admin Settings page clearly indicates this limitation.
- JavaScript syntax and ZIP integrity were checked. The change has not been deployed or live-tested.
