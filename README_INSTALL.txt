ARMAADHA GALLERY — NATIVE PHOTO VIEWER + SWIPE

- Photos now open as native images in the app instead of Google Drive's embedded preview iframe.
- This allows the app's swipe-left / swipe-right navigation to receive touch gestures.
- Download icon remains at the top-right.
- Videos continue to use the Drive preview iframe.
- No text labels or visible Previous/Next buttons are added.

Install:
1. Replace index.html in GitHub Pages and commit.
2. No Code.gs change is needed for this viewer display update.
3. Hard refresh with Ctrl+Shift+R. If using the installed PWA, clear site data/reinstall if it shows old code.

Note: The image thumbnail URL must be accessible to the signed-in viewer. Live testing against your Drive account has not been performed.
