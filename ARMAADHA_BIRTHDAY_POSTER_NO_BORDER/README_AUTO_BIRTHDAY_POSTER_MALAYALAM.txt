ARMAADHA – AUTO BIRTHDAY POSTER UPDATE

മാറ്റങ്ങൾ:
1. Dashboard-ൽ ഇന്ന് ജന്മദിനമുള്ള വിദ്യാർത്ഥികൾക്കായി Poster സ്വയം കാണിക്കും.
2. ഇനി Create Poster ബട്ടൺ അമർത്തേണ്ടതില്ല.
3. നൽകിയ EKC Connect മാതൃകയെ അടിസ്ഥാനമാക്കിയ കറുത്ത പശ്ചാത്തലത്തിലുള്ള ഡിസൈൻ.
4. വിദ്യാർത്ഥിയുടെ Profile Photoയും പേരും മാത്രം വ്യക്തിഗത വിവരങ്ങളായി കാണിക്കും.
5. Admission Number, ക്ലാസ്, ഇമെയിൽ, ഫോൺ, മറ്റു വിവരങ്ങൾ Poster-ൽ കാണിക്കില്ല.
6. Happy Birthday! / Wishing you a fantastic day ahead! എന്ന ആശംസകൾ മാത്രം കൂടെയുണ്ടാകും.
7. ഇന്ന് ജന്മദിനമുള്ളവർ ഇല്ലെങ്കിൽ പഴയപോലെ അറിയിപ്പ് കാണിക്കും.

INSTALL:
1. ZIP Extract ചെയ്യുക.
2. GitHub repository-യിലെ index.html മാത്രം replace ചെയ്ത് Commit ചെയ്യുക.
3. Code.gs / config.js മാറ്റേണ്ടതില്ല.
4. Browser refresh ചെയ്യുക (Ctrl + Shift + R).

കുറിപ്പ്: Poster Dashboard-ൽ സ്വയം പ്രസിദ്ധീകരിക്കുന്ന രീതിയിലാണ്. Birthday notification data ലഭ്യമാകുകയും വിദ്യാർത്ഥിയുടെ profile photo set ചെയ്തിരിക്കുകയും വേണം. Live deployment പരീക്ഷിച്ചിട്ടില്ല.
